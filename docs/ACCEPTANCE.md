# 版本验收

## v1.1.0 本次验证

116 项 Python 测试通过，覆盖原有 70 项及敏感信息、捕获预算、预筛、删除确认与失败回滚。JavaScript 语法检查与 Chromium 操作验证通过：模型删除先提出请求，用户确认后才删除；确认后的撤销、取消请求、按类型授权直接删除、旧敏感记忆隔离标记可用，320/390 像素各页面无横向溢出，无页面脚本错误。浏览器使用脚本模型，验证实际 HTTP/工具/数据库路径，不能代表真实模型判断质量。

56 条合成样本离线预筛检查已完成，没有 API 调用。真实模型分类评测尚未执行：当前环境没有密钥。样本、评分脚本与运行方式见 [evaluations/README.md](../evaluations/README.md)。

新增验证包含：

- 捕获、所有记忆写入者、候选确认、修改采纳、撤销恢复均拒绝识别到的敏感信息。
- 旧敏感记忆不进入模型上下文、搜索或直接读取；历史、当前消息及工具结果在出站前过滤。
- 分类失败也消耗捕获尝试额度；捕获达到上限或触及聊天预留额度后，正常回答继续。
- 各类型模型删除默认待确认；模型/捕获器不能授权或确认；请求跨重启保留。
- 相同删除请求去重，重复确认/取消幂等；目标、关联提醒或项目任务变化后拒绝旧确认。
- 正在执行的提醒不可删除；失败确认不留下部分删除；确认删除仍可事务撤销。

## 在真实部署上再核验

当前开发环境没有真实 DeepSeek/飞书凭据。模拟接口与本机浏览器测试不会替代以下平台验收：

1. `python3 -m lumen --check` 验证配置与库完整性，启动后检查 `/api/health` 显示 1.1.0。
2. 飞书发送「记住我喜欢简洁回答」，用 `/memory` 检查；更正后重新查询；再要求忘记，用 `/pending` 查看请求、`/confirm ID` 确认。
3. 发送一个多步目标；`/plans` 查看草稿；`/approve ID` 后 `/todos` 检查，重复确认不增加任务。
4. 设置两分钟后的提醒，在浏览器关闭后接收飞书推送；检查运行和发送回执。
5. 断网后恢复，已保存的队列继续发送；长消息次序正确。
6. `/today`、`/review`、`/status`、`/undo` 按预期工作。
7. 下载备份，停服务，在单独数据库路径恢复，检查个人数据和 `PRAGMA integrity_check`。
8. 连续使用观察响应质量、提醒时效与用量；自然语言理解质量依赖所选模型，不能由版本号证明。
9. 使用合成敏感样本验证捕获不写入、网页旧记忆显示隔离；不要用真实密码或证件来做测试。
10. 在注入模型凭据的环境运行 `scripts/evaluate_capture.py --live`，记录真实 precision/recall、失败与敏感输出，不能用离线成绩替代。

## 重要边界

- 单用户、文本渠道、个人事务；没有电脑控制、邮箱/支付执行、多用户或外部账号连接器。
- 无永久 exactly-once 保证。飞书使用稳定 UUID 和持久去重；异常中断不盲目重新执行已有写入。
- SQLite、备份和 JSON 导出含个人信息，文件权限收紧但没有应用层加密。
- 删除/过期会移除后续模型上下文；历史聊天、发送记录和恢复用操作记录保留在本机。不是外部模型数据删除。
- 模型工具调用有数量、时间和成功调用预算；超限会明确中止并列出已成功写入。
