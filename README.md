# Lumen · 个人事务助手

**v1.0.0** — 把对话变成进展。

Lumen 在你常用的飞书里陪你聊天，记住你确认的信息，保存想法和资料，把目标拆成可以跟进的事情，再按你指定的节奏提醒与回顾。网页是同一套个人数据的工作台。

它的主线是「聊天 → 记住 → 计划 → 跟进 → 回顾」。每一次事务修改都有回执，可检查、可纠正、可撤销；计划先给草稿，确认后才落地；主动简报由你开启。

## 能力

| 场景 | 能力 |
| --- | --- |
| 对话 | DeepSeek / OpenAI 兼容 tool calling、多轮上下文、新对话、重复请求去重、模型用量预算 |
| 了解你 | 已确认与候选记忆、类别、有效期、按 ID 更正、忘记与旧上下文隔离 |
| 管事情 | Todo 的优先级、截止、备注、项目归属、关联提醒，完成后停止关联提醒 |
| 推进目标 | 项目与目标、可编辑计划草稿、确认后事务化创建项目和任务、进度查看 |
| 保存想法 | 笔记、标签、关键词搜索、真实记录引用；正文按需读取 |
| 到时执行 | 一次/每天/每周/工作日/每月，改期、改内容、暂停、稍后提醒，后台 Agent 任务 |
| 主动回顾 | 今日简报与近七天回顾，不依赖模型，显式启用周期推送 |
| 可掌控 | 操作回执、冲突检查后撤销、JSON 导出、SQLite 一致性备份、离线恢复、运行状态 |

v1.0 是完整的**单用户个人事务助手**，文本渠道以飞书和网页为主。电脑控制、语音、邮箱/日历账号、支付、多用户和第三方工具市场需要额外接入与验收，未实现的能力不会伪装成已经完成。

## 五分钟启动

Python 3.11+，无需 Go、Node、Redis、向量数据库或本地模型。

```bash
python3 -m pip install -r requirements.txt
export LUMEN_MODEL_API_KEY='你的模型密钥'
export LUMEN_MODEL_BASE_URL='https://api.deepseek.com'
export LUMEN_MODEL='deepseek-chat'
export LUMEN_FEISHU_APP_ID='你的飞书 App ID'
export LUMEN_FEISHU_APP_SECRET='你的飞书 App Secret'
export LUMEN_FEISHU_ALLOWED_USER_IDS='你的个人 open_id'
python3 -m lumen
```

给飞书机器人发个人文本消息，或打开 http://127.0.0.1:8787 。飞书三项全部留空可只用网页；没有模型密钥仍可管理个人数据、使用事务快捷命令和普通提醒/简报。

配置样例见 [deploy/lumen.env.example](deploy/lumen.env.example)。程序不自动加载 .env，应由 shell / 服务管理器注入。兼容旧 `LUMEN_DEEPSEEK_*` 变量，新 `LUMEN_MODEL_*` 优先。默认时区 `Asia/Shanghai`，数据库仍为 `data/lumen-v001.db`，升级无需换库。

OpenAI 的 Base URL 使用 `https://api.openai.com/v1`，设置支持工具调用的模型。其他兼容提供商填入 `/chat/completions` 前的 URL。身份与语气由 `LUMEN_ASSISTANT_NAME`、`LUMEN_ASSISTANT_TONE` 配置。

## 飞书设置

启用自建应用机器人，选择长连接事件接收，订阅 `im.message.receive_v1`，授权 `im:message.p2p_msg:readonly`、`im:message:send_as_bot`，发布并把自己加入可用范围。只允许一个 open_id，仅响应其个人文本消息，忽略群聊与其他用户。无需公网回调端口。

收消息先写持久队列，发送使用持久队列和稳定 UUID，断网后退避重试。重复入站和网页请求 ID 去重；长回复分段保持顺序。执行中异常中断会标记出来，避免盲目重复已有写入，仍不承诺永久 exactly-once。

## 日常用法

- 「记住：我喜欢直接简洁的回答。」
- 「这条信息只保留到下周五：我在上海出差。」
- 「帮我拟一份学完数据库课程的计划，分成五步。」
- 确认后：「把第一课设为高优先级，明天截止，今晚八点提醒我。」
- 「保存笔记：SQLite 事务要点……」「找一下关于事务的笔记。」
- 「每个工作日早上九点发我今日简报。」「每周日晚八点发我本周回顾。」
- 「这个提醒改到明天下午三点。」「忘记我的临时地点。」

计划草稿不会创建任务，用网页确认或 `/approve ID` 落地。候选记忆用网页确认或 `/remember ID` 后进入个人上下文。记录很多时按需搜索，初始上下文与最近聊天有大小限制。

| 快捷命令 | 作用 |
| --- | --- |
| `/help` | 查看命令 |
| `/new` 或「新对话」 | 重置短期上下文，保留个人数据 |
| `/today`、`/review` | 今日简报、近七天回顾 |
| `/todos`、`/projects`、`/notes`、`/memory` | 查看个人记录 |
| `/plans`、`/approve ID`、`/reject ID` | 查看、确认、取消计划 |
| `/remember ID` | 确认候选记忆 |
| `/reminders`、`/snooze ID 分钟` | 查看、推迟提醒 |
| `/undo`、`/undo 操作ID` | 撤销最近或指定操作，遇到后续变化拒绝覆盖 |
| `/status` | 版本、用量、失败任务与待发送数量 |

ID 可以用唯一的前八位。以上命令不消耗模型调用。

## 提醒、备份与成本

服务保持运行才能按时执行，浏览器关闭不影响飞书推送。重复任务离线积压只补一次，然后跳到下一次未来时间，避免轰炸。工作日指周一到周五，不自动处理法定节假日；月度按初始日期锚定，短月份取末日，后续恢复原日期。

Todo 截止和提醒是独立时间，明确创建关联提醒后，任务完成会停掉它。执行失败的任务暂停，需检查后重新启用。定时 Agent 不能修改个人记忆、创建其他定时任务或确认计划。

默认每日模型成功调用上限 120，可配置 `LUMEN_MODEL_DAILY_CALL_LIMIT`，包含一次对话里的每轮工具调用。统计供应商返回的输入/输出 token，不估算货币价格。事务命令、普通提醒和确定性简报不使用模型。

默认每日自动一致性备份，自动备份保留最近七份；网页「今日」可导出个人数据或下载备份。离线备份/恢复、systemd 部署、远程访问和回滚见 [部署说明](deploy/README.md)。

## 升级与隐私

从 v0.01.1 升级：停止服务、备份原 SQLite、拉取代码、安装依赖、重启。数据库按增量加表/字段，不清空记忆或任务；已有凭据继续使用。每个开发阶段都有独立 Git 提交，旧版活动采集代码和文档已完全移除。

模型会收到当前已确认记忆、最近聊天和按需读取的个人记录；飞书会收到对话与任务结果。凭据留在进程环境，不通过 API 返回，也不进入 Git。数据库与备份收紧权限，但没有应用层加密。

敏感信息在本地检查：识别到的密码、验证码、密钥、证件号码和银行卡号不能保存为记忆，包括自动捕获、显式保存、候选确认、修改采纳和撤销恢复。捕获输入含敏感信息时跳过分类；发给模型的当前消息、历史及工具结果会隐藏检测到的敏感行。旧库里的敏感记忆停止进入模型上下文，面板标出隔离状态，但不自动删除本地原文。

过滤是规则保护，不是完整的隐私识别器。银行卡使用号码形态与 Luhn 校验，证件使用常见形态和标签；无标签的任意密码、未覆盖的格式和语义改写可能无法识别。聊天、笔记、导出与备份仍可能含本地原文，请不要把应用当密码或证件保险箱。

忘记/过期会隔离后续模型上下文；原始聊天、发送历史和用于撤销的操作数据仍留在本机。用户重新提及会形成新输入。这不是对外部模型提供商的数据删除。

## 开发与验收

```bash
make test
make check
python3 -m lumen --check
```

[路线图与研究依据](docs/ROADMAP.md) · [验收与真实平台检查](docs/ACCEPTANCE.md)

```text
lumen/agent.py         对话、模型、事务命令与请求去重
lumen/actions.py       参数、权限边界与事务写入
lumen/domain.py        个人记录、搜索、计划与操作回执
lumen/core.py          SQLite 与兼容入口
lumen/migrations.py    增量数据升级
lumen/scheduler.py     定时执行与持久结果
lumen/briefing.py      基于真实任务的简报
lumen/feishu.py        长连接与持久收发
lumen/operations.py    撤销、导出、备份与恢复
lumen/static/         网页工作台
```

自动化和浏览器测试覆盖实现与失败路径。真实模型质量、飞书网络及服务器常驻状态需要在你的部署上验收，模拟接口通过不能替代平台联调，也不能证明比任何竞品全面更强。
