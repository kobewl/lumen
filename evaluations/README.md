# 捕获质量评测

`capture_samples.json` 包含 56 条合成样本：Soul、日常、混合事实、沿用已有 key、寒暄、事务、问句、转述、假设、显式请求和敏感值。测试数据不来自聊天库；银行卡示例为行业测试号码，其他标识为虚构样本。

先审查预筛，不发网络请求：

```bash
python3 scripts/evaluate_capture.py --output /tmp/lumen-screening.json
```

`classification: null` 表示没有测过模型质量。`screen_missed_fact_ids` 只衡量这批样本的预筛遗漏，不能泛化为零漏记。显式记住请求由聊天工具处理，标记 `pipeline_capture: false`，不算预筛遗漏。

在已有模型密钥的部署环境中运行真实模型。沿用进程环境，不把密钥写进命令参数、样本、报告或 Git：

```bash
python3 scripts/evaluate_capture.py --live --max-calls 60 --output /安全路径/lumen-capture-evaluation.json
```

没有密钥会在发送请求前退出。运行不会加载真实个人数据库：使用临时独立库统计模型预算，本次最多尝试指定次数，仍受 `LUMEN_MODEL_DAILY_CALL_LIMIT` 约束。默认对所有不含敏感信息的样本直接调用分类模型，包括被预筛跳过的负样本；敏感样本只测本地拦截，不把原值发给提供商。会产生实际 API 费用，不自动重试。

报告包含模型名、数据集与提示词哈希、调用尝试、每条样本的状态，以及 TP/FP/FN 和 precision/recall，不保存密钥或原始模型输出。文件权限为 0600。达到调用上限、接口错误、非法条目或敏感输出会返回失败状态，不能拿不完整的报告当通过。

匹配使用目录、必要内容词和部分样本的已有 key，是可重复的初步评分，不等于完整语义评审。请根据实际失败案例扩充样本，检查同义表达、隐含事实、方言、跨语言和过期时间。此批数据没有验证所有时间解析场景，也没有测对话模型的整体回答质量。

截至本次开发：仅完成离线预筛与脚本验证；没有可用密钥，尚无真实模型分类成绩。
